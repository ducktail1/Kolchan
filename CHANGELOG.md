# Колчан — история версий

Формат версии: `ГЛАВНАЯ.ФУНКЦИИ.ИСПРАВЛЕНИЯ`
- новая функция → растёт средняя цифра (1.1.0 → 1.2.0)
- исправление без новых функций → растёт последняя (1.2.0 → 1.2.1)

## 1.3.0 — 2026-11-07

### Новое
- Версия для друзей: у каждого своя база на телефоне.
- Приветствие при пустой базе: что такое места, сумки и вещи, кнопка «Начать: добавить место».
- Инструкция «Поставь Колчан на экран «Домой»» при первом открытии в браузере: шаги с картинками для iPhone (Safari) и Android (Chrome); открывается снова из приветствия и из «Данных».
- Кнопка «Отзыв»: сообщение уходит в Telegram @ducktail10, к нему добавляются версия и модель телефона.
- Напоминание о резервной копии, если нет синхронизации, вещей 5 и больше и копия не сохранялась неделю; «Позже» — отложить на 3 дня.
- Номер версии в окне «Данные».

### Изменено
- Синхронизация с GitHub свёрнута и помечена как необязательная, поле репозитория по умолчанию пустое.
- Если браузер не даёт сохранять данные (частный режим, встроенный просмотр), приложение работает без сохранения и предупреждает об этом.

## 1.2.0 — 2026-11-07

### Новое
- База синхронизируется с приватным репозиторием `kolchan-data` (файл `data.json`).
  - При открытии приложения, при возврате в него, через 8 секунд после изменений и по кнопке «Синхронизировать».
  - Без интернета всё работает как раньше, синхронизация пройдёт, когда сеть появится.
  - Правки с телефона и от Claude объединяются: по каждой вещи побеждает более свежее изменение, история перемещений склеивается, удаления учитываются.
  - Каждая синхронизация — коммит в `kolchan-data`, можно откатиться на любой момент.
- В «Данных» — поле для токена GitHub и состояние синхронизации; при ошибке на кнопке «Данные» появляется ⚠.

## 1.1.0 — 2026-11-07

### Новое
- Кнопка «Домой» (значок домика слева от названия) — с любого экрана на главную.
- Раздел «Перемещения» на главной: сумки в пути, откуда/куда, с какого числа, сколько вещей; кнопки «Что внутри», «Изменить», «Принять».
- Кнопка «⇄ Переместить»:
  - «Отправить сумку» — выбор сумки, галочками что едет (уже лежащее отмечено), куда, через «В пути»;
  - «Изменить перемещение» — добавить/убрать вещи из сумки в пути, поменять «куда»;
  - «Принять сумку» — отметить, что приехало, неотмеченное уходит в «Не нашлись»;
  - «Вещи» — переложить несколько вещей галочками.
- Создание вещи прямо из поиска при перемещении — сразу кладётся в сумку.
- Кнопка «+ Добавить» спрашивает, что добавить: вещь, сумку или место.
- Добавление из пустого поиска: «+ Добавить «…»» с подстановкой названия.
- Несколько вещей за раз через запятую в поле «Что».
- Выпадающий список мест с пунктом «+ Добавить место хранения…».
- Главная страница со свёрнутыми разделами «Перемещения / Сумки / Места хранения / Все вещи».
- Поиск скрывает места и сумки, где ничего не нашлось.
- Крестик ⊗ для быстрой очистки в каждом текстовом поле.
- Жесты: свайп от левого края — назад, свайп вниз за заголовок или список — закрыть окно.
- Номер версии в окне «Данные».

### Исправлено
- Прокрутка списка вещей в окне перемещения.
- Страница не увеличивается при вводе текста на iPhone.

## 1.0.0 — 2026-11-06
- Первая версия: места, сумки, вещи, история перемещений, сверка сумки, заметки, фото, выгрузка и загрузка базы файлом, работа без интернета.
