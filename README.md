# Колчан

Личная база вещей: где что лежит, сумки, которые переезжают с содержимым, история каждой вещи.
Офлайн-приложение для iPhone (экран «Домой»). База хранится на телефоне и синхронизируется с **приватным** репозиторием `kolchan-data`. В этом (публичном) репозитории только код, данных нет.

Открыть: https://ducktail1.github.io/Kolchan/

## Ветки

| Ветка | Зачем |
|---|---|
| `main` | Рабочая версия. С неё GitHub Pages раздаёт приложение на телефон. Напрямую сюда не пишем. |
| `dev` | Разработка: новые функции и исправления копятся здесь. |

## Как выходит новая версия

1. Изменения складываются в `dev` (коммит на каждую функцию или исправление).
2. В `CHANGELOG.md` добавляется раздел с номером версии и списком изменений, номер обновляется в `sw.js` (`VERSION`) и в окне «Данные».
3. Открывается Pull request `dev → main`. Смотришь изменения → **Merge**.
4. На `main` ставится тег `v1.2.0` и выпускается Release с текстом из CHANGELOG.
5. Через 1–2 минуты GitHub Pages обновится. На телефоне закрой и открой Колчан — подтянется новая версия. База не пострадает.

## Откат

Если новая версия сломалась: в Pull request нажми **Revert** — `main` вернётся к прошлой версии.

## Файлы

- `index.html` — приложение
- `local.js` — хранение базы на телефоне, выгрузка и загрузка файла
- `sw.js` — работа без интернета (кэш), `VERSION` = номер версии
- `manifest.webmanifest`, `icon-*.png` — имя и иконка на экране «Домой»
