КОЛЧАН — офлайн-приложение для iPhone

Приложению нужен адрес в интернете только один раз, чтобы установить его.
Дальше оно работает без сети, а база хранится в памяти телефона.
Сами вещи в интернет не выкладываются: на GitHub лежит только пустое приложение.

1. ВЫЛОЖИТЬ ПРИЛОЖЕНИЕ (бесплатно, через GitHub Pages)
   а) Зарегистрируйся на github.com (можно с телефона).
   б) New repository → имя, например, veshchi → Public → Create.
   в) «uploading an existing file» → выбери все файлы из этой папки, кроме этой инструкции
      (index.html, app.js, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png) → Commit.
   г) Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
   д) Через 1–2 минуты появится адрес вида https://ТВОЙ-ЛОГИН.github.io/veshchi/

2. УСТАНОВИТЬ НА iPHONE
   а) Открой адрес в Safari.
   б) «Поделиться» → «На экран Домой» → «Добавить».
   в) Открывай приложение только с иконки: так iOS не чистит его данные.

3. ПЕРЕНЕСТИ ТЕКУЩУЮ БАЗУ
   а) Сохрани файл veshchi-2026-11-05.json из чата в «Файлы».
   б) В приложении: «Данные» → «Загрузить файл» → выбери его → «Заменить базу».
   Появятся 63 вещи, 5 сумок, 10 мест и вся история.

4. РЕЗЕРВНАЯ КОПИЯ И ОБМЕН С CLAUDE
   «Данные» → «Выгрузить файл» → сохрани в «Файлы» или отправь в чат Claude.
   Файл, который вернёт Claude, загружается там же: «Загрузить файл».
   Загрузка заменяет всю базу на телефоне содержимым файла.

5. ОБНОВЛЕНИЯ
   Если Claude пришлёт новую версию app.js или index.html — замени файлы в
   репозитории и в sw.js поменяй VERSION = "v1" на "v2". База на телефоне не пострадает.
